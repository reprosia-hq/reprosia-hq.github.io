An independent project to make AI-assisted analysis auditable.

Reprosia grew out of open-source R packages for regulated statistics. It exists because the next question after "is the result right?" is "can you show how you know?".

How the work is approached.

Open source first
The evidence tools are public on CRAN and GitHub, so anyone can read the code that produces the record.
Claims match evidence
Software is described as designed around a regulation, never as compliant with it. Features that are not built are labelled as plans.
Statisticians decide
The tools record and verify. Judgement about methods and models stays with the people accountable for them.
Humans review AI output
An AI draft is not evidence until a named person has reviewed it and the decision is on record.
Plain about status
What is available, what is being built and what is only an idea are separated on every page.

Founder.
