Try the audit layer in your browser.

Three tools. The workbench, the readiness check and the keyword search run entirely on this page: nothing is uploaded. The AI draft in the workbench is simulated.

What you will see: fix the scope, the data and the environment, capture an AI draft, record a human review, then replay the fingerprints. If anything changed after the review, the review is marked stale and has to be redone. Every step is written to the evidence log on the right.

1. Scope the task

Record what the assistant may do and how the result will be used.

Illustrative rule: one named reviewer is enough for this context of use.

2. Fix the data and environment

Fingerprints tie the run to an exact dataset and software environment, before any code is drafted or reviewed.


          

        


        

          
3. Capture the AI draft

          
The prompt, the model and the output are logged as one entry, with a separate fingerprint for the prompt and for the output.

          
Prompt (fixed in this demo)

          

          
Draft

          
The draft appears here once generated.

          

          
Simulated. The code is canned and no model is called. One of the three drafts contains a planted error: read the code before you decide.

        


        

          
4. Record the review

          

          
A named person accepts, edits or rejects the draft. Edits and rejections need a reason. The decision joins the chain. Reviewers must differ from each other and from the person who scoped the task. Names are not authenticated in this demo.

          

          

          

            

              
            

          

          

            
            
            

          

          

        


        

          
5. Replay check

          
Recompute the fingerprints of the code, the data and the environment and compare them with the logged ones. This demo does not run R. A real replay re-runs the code and compares the outputs as well.

          
          
          

          
Run it once with both boxes cleared to see a clean pass, then with a box ticked to see a difference.
