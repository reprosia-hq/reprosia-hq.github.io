# Reviewer checklist for AI-assisted output

Use one copy per output. Record the result under your own name.

- [ ] The output matches the task recorded in the context of use.
- [ ] I read the code or text in full, not only the result.
- [ ] The inputs are the intended data version, and the fingerprint is recorded.
- [ ] Exclusions and derivations match the specification or SAP.
- [ ] The result was checked independently (second implementation, spot check or known values).
- [ ] The run can be replayed in the locked environment with the same result.
- [ ] My decision (accepted, edited or rejected) and my reasons are recorded.
- [ ] Any edits I made are captured, not only the final version.
- [ ] Anything surprising has been escalated to the tool owner.
- [ ] The limits in the context of use were respected (no excluded tasks or data).
